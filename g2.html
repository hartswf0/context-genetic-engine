THEORY OF THE PROGRAM
PROMPT = GENOTYPE  ·  COMPLETION = PHENOTYPE
CONTEXT = FIELD  ·  USER = BREEDER

1. PALETTE — Write a target behavior, then click Synthesize to build a full prompt genome. Use Mutate to refine it, or Diverge for radical exploration.

2. GENOTYPE — The DNA sequence. Click a gene row to expand/edit its payload. Toggle EXON/INTRON to silence instructions. Manually inject codons from the chip bank. Use the Lineage Bank to switch context or create new branches.

3. MATRIX — Enter a directive in the Palette, then click Breed Matrix to cross your active genome with an AI-generated parent, producing 4 Mendelian offspring in a 2x2 grid.

4. FIELD — The execution environment. Enter your task, then click Express to run the system prompt against the model.
