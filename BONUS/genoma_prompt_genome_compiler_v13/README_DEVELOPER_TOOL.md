# GENOMA Prompt Genome Compiler v13

Final-shot reset. The live page is F0 evidence. The prompt genome is the main artifact. The prompt genome compiles into standalone program text / HTML rather than trying to patch the whole page.

## Flow
1. Configure model.
2. Encode Prompt Genome.
3. Compile Program Text.
4. Open Artifact Page.
5. Mutate prompt codons and recompile.

## Model routing
- Reasoning model: page evidence -> prompt genome, prompt genome -> program text.
- Fast model: single codon mutation.

## Main differences from v12
- No live page overlay as the center.
- No original/child/diff clutter.
- Operation genome is secondary.
- Artifact is visible in a dedicated artifact page and preview.
