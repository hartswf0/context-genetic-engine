# GENOMA Prompt Genome Compiler v14

A filmable, more-with-less Chrome side-panel tool. The live page is captured as F0 evidence, encoded by the reasoning model into a prompt genome, then compiled into a standalone HTML/CSS program-text artifact.

## Core loop
1. Encode Genome
2. Compile Artifact
3. Open Artifact
4. Mutate one codon and recompile

## v14 changes
- Hides model names in the main UI. Shows only KEY NEEDED / REASONING ON / RUNNING / READY.
- Adds an active F0→Prompt Genome→Program Text domestication animation in the panel and on-page HUD.
- Tightens the interface for filming: fewer labels, less debug exposure, stronger status, and a pulsing Open Artifact button when ready.
- Updates compiler prompt to produce substantial but uncluttered artifacts.

Remove older GENOMA builds from chrome://extensions before loading this folder.
